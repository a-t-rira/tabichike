プライバシーポリシー

旅行アプリ「たびチケ」（以下「本アプリ」）で、どんな情報をどこに保存し、どう扱うかを説明します。

IN SHORT

  • 会員登録はなく、名前やメールアドレスは集めません
  • ひとりで使う旅行は、あなたの端末の中だけに保存されます
  • 「みんなで編集」にした旅行だけ、サーバー（Google Firebase）に保存されます
  • アクセス解析は Cookie を使わず、旅行の内容は送りません
  • 旅行の内容を広告や販売に使うことはありません

01運営者

本アプリは「チップ商会」が運営しています。お問い合わせは X（@chip_shokai） のダイレクトメッセージで受け付けています。

02ひとりで使う旅行のデータ

旅行のなまえ・日程・旅程・持ち物・費用・メモなど、本アプリに入力した内容は、通常は お使いの端末のブラウザの中（localStorage）だけ に保存されます。運営者のサーバーには送信されず、運営者が見ることもできません。

ブラウザのデータを消すと、保存した旅行も消えます。端末の買い替えなどに備えて、設定の「データを書き出す」で控えを取ってください。

03「みんなで編集」にした旅行のデータ

旅行を「みんなで編集」にすると、一緒に編集できるように、その旅行の内容が Google が提供する Firebase（Cloud Firestore）に保存されます。保存場所は東京リージョン（asia-northeast1）です。

保存するもの旅行のなまえ・行き先・日程・一緒に行く人の名前・予算・メモ、旅程、持ち物リスト、費用、「行った！」スタンプ、ニックネーム（最後に変更した人の表示用）、変更日時
保存しないもの持ち物のチェック状態（各自の端末にだけ保存）、ひとりで使っている旅行
端末を区別する情報Firebase Authentication の匿名ログインで自動発行されるID。旅行をつくった人を判別するためだけに使い、個人を特定する情報とは結びつけません

招待リンクについて：招待リンクを知っている人は、だれでもその旅行を見たり編集したりできます。リンクを送る相手には十分ご注意ください。住所や電話番号など、他人に見られて困る情報は入力しないことをおすすめします。

04共有リンク

「旅行を共有」で作るリンクには、旅行の内容がリンクの中（URLの「#」より後ろ）に入っています。この部分はサーバーに送られず、運営者のもとには保存されません。ただし、リンクを受け取った人はだれでも内容を見られます。

05アクセス解析

本アプリとこのサイトでは、閲覧数を知るために Cloudflare, Inc. の Cloudflare Web Analytics を使っています。Cookie は使わず、ページの閲覧数などを集計するもので、旅行の内容は送信しません。共有リンク・招待リンクで開いたときは、アクセス解析を読み込みません。

06外部サービス

  • Google Firebase（Cloud Firestore・Authentication）：「みんなで編集」した旅行の保存と、匿名ログインに使用
  • Cloudflare Web Analytics：アクセス解析に使用
  • Google Fonts：画面の文字の表示に使用
  • GitHub Pages：本アプリのファイルの配信に使用

これらのサービスでは、通信のためにIPアドレスなどの情報が各社に送られることがあります。各社での取り扱いは、それぞれのプライバシーポリシーをご確認ください。

07利用目的

保存した情報は、本アプリの機能（旅行の保存・共同編集・表示）の提供と、不具合の調査・改善のためだけに使います。旅行の内容を広告に使ったり、第三者に販売したりすることはありません。法令にもとづく場合を除き、第三者に提供することもありません。

08データの削除

  • ひとりで使う旅行：旅行の「…」→「削除」、または設定の「すべてのデータを削除」で消えます
  • みんなで編集している旅行：旅行をつくった人が「みんなの旅行を削除」を押すと、サーバーから削除され、メンバー全員の画面からも消えます。メンバーが「この旅行から抜ける」を押しても、サーバー上の旅行は消えません
  • つくった人が端末を変えた・アプリのデータを消したなどで削除できなくなった場合は、お問い合わせください（招待リンクを添えてください）

09安全のための取り組み

サーバーに保存した旅行は、招待リンクに含まれる推測できないIDを知らないと読み書きできないように設定しています。旅行の一覧を取得することはできません。ただし、インターネット上のサービスである以上、完全な安全を保証することはできません。

10このポリシーの変更

機能の追加などにあわせて、このポリシーを変更することがあります。変更したときは、このページで内容と日付をお知らせします。
