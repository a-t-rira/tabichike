GATE1

旅行のチケットをつくる

たびチケでは、旅行ひとつが「搭乗券」1枚になります。まずはチケットを発券しましょう。

  1. ホーム画面の右下にある ＋ ボタンを押します。
  2. 旅行のなまえ、出発日、帰る日 を入れます。行き先・一緒に行く人・予算・メモは、あとからでも大丈夫です。
  3. 好きな チケットの色 を5色から選んで、保存 を押せば発券完了です。

持ち物の基本セット：新しくつくるときは、財布やスマホの充電器などの「基本セット」が最初から持ち物リストに入ります。いらなければ、作成画面のチェックを外してください。

出発案内板の見かた

ホームの一番上にある紺色の案内板には、いちばん近い旅行が表示されます。出発前は「あと◯日」、出発当日は「TODAY」、旅行中は「◯日目」に切り替わります。案内板を押すと、その旅行の画面が開きます。

チケットの編集・複製・削除

ホームのチケット右上の ••• から、編集・複製・削除 ができます。複製すると、旅程や持ち物をそのままコピーした新しいチケットができるので、同じ場所に毎年行く旅行などに便利です（費用はコピーされません）。

GATE2

旅程と「行った！」スタンプ

予定を入れる

チケットを開くと 旅程 タブが表示されます。右下の ＋ から、日にち・時刻・カテゴリ（移動・観光・食事・宿・その他）・やること・場所・メモを入れて保存します。時刻が決まっていない予定は、空欄のままで「未定」としてその日の最後に並びます。

予定は「DAY 1」「DAY 2」…と日ごとの時間割になり、点線のルートでつながります。予定を押すと、あとから編集・削除ができます。

行った場所にスタンプを押す

旅行の当日以降になると、予定の右に 行った？ ボタンが出ます。押すと赤い VISITED のスタンプが押されます。その日の予定を全部押すと、日付の横に DAY COMPLETE のスタンプが押されます。

間違えて押したときは、スタンプをもう一度押せば外れます。まだ来ていない日の予定には「行った？」ボタンは出ません。

GATE3

持ち物リスト

持ち物 タブでは、貴重品・電子機器・衣類・洗面・その他のカテゴリごとにリストをつくれます。

  • テンプレートから追加：「基本セット」「泊まりセット」「海外セット」「雨セット」からまとめて追加できます。同じ名前のものは重複して入りません。
  • 右下の ＋：1つずつ追加。保存して続けて追加 で連続入力もできます。
  • 入れたものにチェックを付けると、カテゴリの下のほうへ移動します。
  • 削除したあとは、画面下に出る 元に戻す で取り消せます。

次の旅行で使い回すときは、チェックを全部外す で一気にリセットできます。

GATE4

費用と予算

費用 タブでは、交通費・宿泊費・食費などをメモして、旅行の合計を確認できます。

  1. 右下の ＋ から、なにに使ったか・金額・カテゴリ・日にちを入れます。
  2. 上のカードに合計が出て、予算を決めていれば「のこり」も表示されます。
  3. カテゴリ別内訳で、何にいくら使ったかがひと目でわかります。

予算は、チケットの 旅行を編集 から設定・変更できます。割り勘の計算には対応していません。

GATE5

しおりの印刷・PDF

チケットの画面の下にある しおりを見る を押すと、旅程・持ち物・予算・メモをまとめた「旅のしおり」になります。表紙はパスポート風のデザインです。

  • 印刷・PDF：A4サイズで印刷できます。印刷画面の送り先で「PDFに保存」を選べば、PDFファイルにもできます。
  • テキストでコピー：旅程と持ち物を文章にしてコピーします。メールやメモアプリに貼り付けたいときに便利です。

持ち物は、印刷して手でチェックできるように空欄の□で出ます。行った場所のスタンプは、しおりの旅程にも小さく押されます。

GATE6

旅行を共有する

共有リンクを送る

  1. チケットの画面右上の ••• から 旅行を共有 を選びます（しおりの 共有 ボタンからも開けます）。
  2. メモ・予算と費用を一緒に送るかをスイッチで選びます。最初は「メモは送る」「予算と費用は送らない」になっています。
  3. LINEで送る か リンクをコピー で相手に送ります。

受け取った旅行を取り込む

リンクを開いた人は、しおりを見るだけでなく 自分のたびチケに取り込む を押して、自分の旅行として保存できます。取り込んだ旅行は、スタンプや持ち物のチェックが外れた状態で入ります。

iPhoneでホーム画面に追加している人へ：LINEなどで受け取ったリンクは、Safariで開きます。iPhoneでは、ホーム画面に追加したたびチケとSafariとでデータの保存場所が別なので、Safariで取り込んだ旅行はホーム画面のたびチケには出てきません。その場合はリンクをコピーして、ホーム画面のたびチケの 設定 → 共有リンクから取り込む に貼り付けてください。

共有は「その時点のコピー」です。送ったあとに予定を変えても、相手の画面には反映されません。変更したら、もう一度リンクを送ってください。リンクを知っている人は誰でも旅行の内容を見られるので、送り先には気をつけてください。

GATE7

ホーム画面に追加する

ホーム画面に追加すると、アイコンから全画面で開けて、ふつうのアプリのように使えます。一度開いておけば、電波のない場所でも使えます。

iPhone（Safari）画面下の共有ボタン（□から↑が出ているマーク）→ ホーム画面に追加 → 追加
Android（Chrome）右上の ⋮ → ホーム画面に追加（または アプリをインストール）
パソコンブラウザでそのまま使えます。Chromeなどではアドレスバーの右側からインストールできる場合もあります。

ボタンの名前や場所は、OSやブラウザのバージョンによって少し違うことがあります。

GATE8

データの保存とバックアップ

データは端末の中だけに保存されます

たびチケは会員登録がいらないかわりに、旅行のデータを 使っている端末のブラウザの中だけ に保存しています。サーバーには送られないので、ほかの人に見られる心配はありません。

ここだけは注意してください。ブラウザの履歴やWebサイトのデータを消すと、たびチケの旅行も消えてしまいます。スマホを買い替えたときも、自動では引き継がれません。

バックアップのとり方

  1. ホーム右上の 設定（歯車のマーク）を開きます。
  2. データを書き出す を押すと、すべての旅行が入ったファイル（tabichike-backup-日付.json）が保存されます。
  3. 戻したいときや新しい端末では、データを読み込む からそのファイルを選びます。今のデータに追加する か 今のデータと入れ替える を選べます。

旅行の前と、旅行から帰ったあとに一度ずつ書き出しておくと安心です。

HELPFAQ

よくある質問

たびチケは無料ですか？
無料です。会員登録やログインもいりません。
旅行のデータはどこに保存されますか？
使っている端末のブラウザの中だけに保存されます。サーバーには送られません。ブラウザのデータを消すと旅行も消えるので、設定の「データを書き出す」で控えを取っておくと安心です。
スマホを買い替えたら旅行はどうなりますか？
自動では引き継がれません。古いスマホで設定の「データを書き出す」を押してファイルを保存し、新しいスマホの設定で「データを読み込む」から、そのファイルを選んでください。
一緒に行く人と同時に編集できますか？
同時編集にはまだ対応していません。旅行の共有リンクを送ると、相手はしおりを見たり、自分のたびチケに取り込んだりできます。共有するのは送った時点のコピーなので、予定を変えたらもう一度送ってください。
電波がない場所でも使えますか？
一度開いたことがあれば、電波のない場所でも開いて使えます。共有リンクを送るなど、ネットにつなぐ操作だけは電波が必要です。
Androidやパソコンでも使えますか？
使えます。Webブラウザで動くアプリなので、iPhone・Android・パソコンのどれでも開けます。データは端末ごと・ブラウザごとに別々に保存されます。
旅行は何日間まで登録できますか？
1つの旅行につき30日までです。日帰りの旅行もつくれます。
アクセス解析はしていますか？
ページの閲覧数を知るために Cloudflare Web Analytics を使っています。Cookie は使わず、個人を特定する情報や旅行の内容は送信していません。共有リンクで開いたときは計測もしていません。

無料・登録不要。開いたらすぐ使えます。
